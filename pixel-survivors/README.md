# 像素幸存者 · Pixel Survivors

一款类《吸血鬼幸存者》的**俯视角像素风肉鸽生存游戏**。在有限的地图中不断移动，武器会自动攻击从四面八方涌来的怪物；击杀获得经验升级，每次升级从随机选项中挑选武器或道具来构筑流派。存活 15 分钟后最终 Boss 降临，击败它即可通关。

纯 HTML5 Canvas + 原生 JavaScript 实现，**零依赖、无需构建、无任何外部资源文件**——所有像素美术、音效与芯片音乐都由代码实时生成。

## 如何运行

直接用浏览器（Chrome / Edge / Firefox / Safari）打开 `index.html` 即可游玩。

也可以起一个本地静态服务器：

```bash
npx http-server . -p 8080    # 然后访问 http://localhost:8080
```

## 操作

| 操作 | 键盘 | 鼠标 / 触屏 | 手柄（标准布局） |
| --- | --- | --- | --- |
| 移动 | WASD / 方向键 | 在画面上按住拖动 | 左摇杆 / 十字键 |
| 菜单选择 | 方向键 / WASD | 悬停 | 十字键 / 左摇杆 |
| 确认 | 回车 / 空格 | 点击 | A |
| 返回 | ESC / Backspace | — | B / Select |
| 暂停 | ESC / P | 右上角 ❚❚ 按钮 | Start |

武器全部自动攻击，你只需要专注走位。窗口失去焦点时游戏会自动暂停。

## 游戏内容

- **12 种武器**：皮鞭、魔杖、飞刀、战斧、十字回旋、圣水、大蒜、圣经、雷霆之戒、火焰权杖、寒冰新星、符文追踪者，各 8 级。
- **12 种进化武器**：武器满级 + 持有对应被动道具后，开启精英 / Boss 掉落的宝箱即可进化（如 魔杖 + 空白之书 → 神圣魔杖）。配方可在「收藏图鉴」中查看。
- **13 种被动道具**：力量、护甲、生命、恢复、冷却、范围、弹速、持续、数量、移速、拾取、幸运、经验。
- **12 名可解锁角色**：各自拥有不同的初始武器与属性加成，通过达成成就解锁（如存活 5 分钟、累计击杀 3000、进化武器、通关等）。
- **3 个关卡**：月光墓园 → 幽暗森林 → 熔岩地牢，逐步解锁，敌人更强、奖励更多。每关地图有边界、障碍物和可破坏的火盆。
- **15 种怪物 + 6 个 Boss**：远程、分裂、飞行穿墙等不同行为；Boss 拥有冲锋、跳砸、环形 / 螺旋弹幕、召唤、瞬移、地面陷阱等攻击模式。
- **波次与事件**：每分钟刷怪配置不同，穿插蝙蝠群横穿、怪物包围圈、精英怪（掉落宝箱）和 5 / 10 / 15 分钟的 Boss 战。
- **随机掉落**：经验宝石、金币 / 金币袋、烤鸡（回血）、磁铁（吸取全部经验）、圣十字架（清屏）、时停沙漏、宝箱。
- **局外养成**：用金币在「强化商店」购买 18 种永久强化（含复活、重抽、跳过、封印），可随时全额退款重新分配。
- **其它**：自动存档（localStorage）、收藏图鉴、伤害数字、屏幕震动、音量设置、全屏、手柄震动、结算界面的武器伤害统计。

```
pixel-survivors/
├── index.html          入口
├── css/style.css       像素风界面样式
├── js/
│   ├── util.js         数学、随机数、空间哈希网格
│   ├── sprites.js      全部像素美术（字符点阵 → 画布，自动描边 / 受击白闪 / 冰冻 / 精英金边）
│   ├── data.js         武器、道具、敌人、Boss、角色、关卡波次、局外强化等数据
│   ├── save.js         存档、解锁条件、强化商店

│   ├── input.js        键盘 / 鼠标 / 触屏 / 手柄输入
│   ├── game.js         对局逻辑：刷怪导演、碰撞、Boss AI、掉落、升级、宝箱、进化（及测试用 AI）
│   ├── weapons.js      各武器的开火逻辑与投射物行为
│   ├── render.js       低分辨率整数倍放大渲染、程序化地块、光照与特效
│   ├── ui.js           所有菜单 / 弹窗 / HUD 与空间焦点导航
│   └── main.js         状态机与固定步长主循环
└── tests/
    ├── ui.test.js      端到端界面与输入测试（键盘、鼠标、虚拟手柄、存档等 23 项）
    └── sim.test.js     AI 机器人完整游玩 12 个角色 × 3 关卡的稳定性与数值不变量测试
```

## 测试

测试使用 [Playwright](https://playwright.dev/)（Chromium 无头浏览器）：

```bash
npm install            # 安装 playwright
npx playwright install chromium
npm run test:ui        # 界面与输入测试
npm run test:sim       # 每个角色各完整模拟一局（快进），检查数值不变量并输出平衡数据
npm run test:sim:meta  # 同上，但启用满级局外强化
```

`sim.test.js` 中的 AI 会以 16 方向前瞻评估走位、拾取宝石并自动选择升级，用于验证整局 16 分钟内不会出现报错、数值异常或实体数量失控，并输出每局的存活时间、等级曲线、进化数和各武器伤害，作为平衡性参考。

游戏在浏览器控制台中也暴露了调试接口：`PS.debug.bot = true` 让 AI 代打，`PS.debug.speed = 4` 加速游戏。
